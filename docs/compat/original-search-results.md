# Original-memory native-vector search replay

The private Pi restoration matches the observed Python SDK and deployed wrappers in **105 search cases**: **54 node** and **51 fact** responses, including exact ordering and public JSON. [Final comparison](pi-original-search-20261002/comparison-summary.json) has no mismatches. This reuses stored 3072-dimensional vectors; it does not certify embeddings of new queries or real generation quality.

## Reference and scope

The [Python probe](../../scripts/python-original-search-probe.py) executes the actual restored image's Graphiti 0.28.2 search and AST-extracted deployed MCP wrappers. Captured vectors are supplied explicitly. Embedder/cross-encoder stubs refuse calls. Drivers are constructed outside the event loop, and scoped clones return those preconstructed drivers, preventing implicit index creation. The actual async Redis client maps GRAPH.QUERY to GRAPH.RO_QUERY and rejects non-read commands. The [reference run](pi-original-search-20261002/python-summary.json) records 342 SDK read-only queries, zero provider calls and no reference refusals.

One canonical entity name/vector is selected in each of 43 nonempty entity groups, and one fact/vector in each of 42 nonempty fact groups. Additional cases reuse this cohort for limits 1/25/100, real/absent type labels, center ordering and two-group round-robin collection. Queries comprise 56 Latin, 38 mixed Korean/Latin and 11 Korean strings. Reference responses contain 561 fact occurrences, including 68 with invalid_at, 68 with expired_at and 105 without valid_at. These are occurrences across overlapping cases, not unique corpus counts; the deployed default search has no caller-supplied time filter. See [cohort evidence](pi-original-search-20261002/cohort-preservation-summary.json).

The [Rust maintenance example](../../examples/compat-search-replay.rs) shares the MCP engine's validated search branches and read permits. Replay permits only the two search tools, read-only mode and a finite/nonzero 3072-component vector. The example requires an explicit private fixture and loopback restoration port 16380. No replay parameter or maintenance tool is added to MCP. Default read-only MCP operation remains keyword-only; production query embeddings are a separate configuration gate.

Fixtures, queries, UUIDs, vectors, expected results and optional mismatch responses stay owner-private on the Pi. Stdout contains counts/public field paths; attribute differences collapse to the attributes path. Only sanitized evidence and fixed synthetic fixtures enter Git. [Source hashes](pi-original-search-20261002/source-hashes.json) identify the compared implementation/probes. ## Corrections

- Deployed NodeResult uses Python datetime.isoformat(), preserving +00:00 and six fractional digits, and removes every attribute name containing embedding, case-insensitively. The earlier generic SDK node formatter fixture was the wrong oracle. Facts retain their separately verified Pydantic formatter.
- The node recipe fixes the SDK limit at ten: every group fetches twenty candidates per method and returns at most ten nodes before group collection. Fact methods fetch twice the requested limit per group. Group count no longer divides these windows. COMPAT_SEARCH_CANDIDATES bounds each method; an undersized configured bound fails explicitly instead of silently truncating parity.
- SDK score sorting has no UUID tiebreaker. Removing Rust's extra UUID sorting raised exact matches from [63/105](pi-original-search-20261002/before-ranking-fix.json) to [104/105](pi-original-search-20261002/before-center-fix.json).
- The last difference was a deployed SDK quirk: search_interface is absent, and its fallback zips headers with already-decoded dictionary rows, losing actual neighbor scores. It promotes the center and otherwise retains RRF source order. Compatibility mode preserves that observed behavior; this is not genuine graph-distance ranking certification. Differential regression now supplies the actual dictionary record shape; earlier list-record/operations tests cover different internal paths.

## Validation and limits

Local verification passes 30 nonignored all-feature tests, nine disposable compatibility DB/HTTP tests, fmt and all-target/all-feature clippy with warnings denied. New regression checks node/group windows, DTOs, provider-free default and rejection of invalid vectors/mutation replay. Audit regression now uses a unique group: its intentionally foreign malformed copy survives clear(), so its former fixed group contaminated reruns. All nine isolated tests pass after correction. Local DB: FalkorDB 4.20.4; original-data replay: observed 4.16.6 on the actual Pi.

Operational container identity/start time and healthy status are unchanged, and the backup checksum is unchanged. [Maintenance re-audit](pi-original-search-20261002/preservation-summary.json) is identical before/after for identity/vector digests, scope counts and time/provenance validation in 63 policy groups. This uses the retained verified auditor and does not claim bytewise property equivalence. The restoration/outside-policy graphs remain retained. No operational upstream switch, real provider retry, ingestion or deletion was performed by replay. The final maintenance batch takes 19.858 seconds; this does not certify HTTP latency, cold starts or production peak load.

The subsequent [boundary comparison](original-search-negative-results.md) verifies 82 typed negative/empty-data cases and reruns these 105 positive cases after correction. Remaining gates include new-query embeddings, broader original-corpus retrieval quality, unknown graph/index lifecycle and malformed-schema coverage. Captured-vector parity establishes sampled ranking/DTO behavior. Real-provider writes, fresh OAuth login/modern headers, operational client reconnect/rollback and an explicitly authorized cutover remain separate gates. The user restriction prohibits new Gemini/ER2 calls and choosing a new paid alternative.
